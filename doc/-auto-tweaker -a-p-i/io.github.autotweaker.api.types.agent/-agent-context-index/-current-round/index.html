CurrentRound

@Serializable
data class CurrentRound(val userMessage: UUID, val turns: List<AgentContextIndex.Turn>?, val assistantMessage: UUID?, val finishedToolCalls: List<AgentContextIndex.Turn.Tool>?, val pendingToolCalls: List<@Serializable(with = UuidSerializer::class) UUID>?) : UuidIndex(source)

表示当前正在进行的一个轮次，由一条用户消息开启，LLM 将在一个轮次中进行工具调用 - 推理 - 工具调用的循环。

如果 LLM 在一次响应中没有调用任何工具，这个轮次就会被归档为 CompletedRound。
